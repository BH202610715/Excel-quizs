# 엑셀 함수·명령 300제

첨부 학습 자료를 바탕으로 만든 Excel 연습 퀴즈입니다. 객관식 210문항과 주관식 90문항이 있으며, 난이도별 하·중·상 각 100문항입니다.

## 실행

Node.js 20 이상에서 의존성 설치 없이 실행할 수 있습니다.

```bash
npm run dev
```

브라우저에서 `http://localhost:3000`을 엽니다.

## GitHub Pages

프로젝트 하위 경로를 지원하도록 정적 파일 참조를 상대 경로로 작성했습니다. `npm run build`는 Manus 정적 게시용 `dist/`와 GitHub Pages에서 바로 사용할 `docs/`를 생성합니다. GitHub 저장소의 **Settings → Pages**에서 **Deploy from a branch → main → /docs**를 선택하면 사이트를 제공할 수 있습니다. `docs/`는 빌드 산출물이므로 코드나 문제 은행을 변경한 뒤 다시 빌드하고 함께 커밋해야 합니다.

사이트는 객관식 선택지와 문항 순서를 퀴즈를 시작할 때마다 무작위로 섞습니다. 전체 300문항을 한 회차에 풀거나 난이도·유형·영역별로 필터링할 수 있습니다.
